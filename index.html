Working the shift

How do I close a case?

Read the incident brief, run help, and inspect the virtual files with ls and cat. Use submit <answer> for the specific finding the brief asks for. Some cases also need a simulated fix before you can submit.

What can the shell access?

The shell runs inside this page. All hosts, logs, and files are fictional. Commands have no access to your computer’s shell, local files, or live networks. Completion records are saved in this browser when storage is available.

Keyboard controls

Press Enter to run a command. Use ↑ and ↓ in the input to recall commands from this terminal session. Type hint for a clue or clear to clear the output.
